YoBook API is an open catalog and API for CEHRD textbook metadata, built so students, teachers, schools, researchers, and developers can find official learning resources without building the same scraper again.

Who We Are

YoBook API is a small open-source project focused on making public education metadata easier to browse, test, and reuse. The project is designed as infrastructure for other learning apps, not as a replacement for official publishers or source websites.

Where The Data Comes From

The active catalog uses CEHRD Learning Portal records as the primary source. Lower-quality secondary datasets are archived in the repository for reference, while the public API serves the clean CEHRD-first merged catalog.

What You Can Use

  • Search textbook records by title, subject, grade, and keyword.
  • Fetch one book by ID for detail pages or integrations.
  • Use source and stats endpoints for dashboards and checks.
  • Read the raw active dataset when a static JSON file is easier.

API Example

Use normal HTTP GET requests from any app, website, script, or learning tool.

GET /api/books?grade=10&subject=Science GET /api/books/cehrd-learning-g1-english-42

Attribution And Ownership

The code, normalization logic, and API structure are open source. Textbook PDFs, cover images, trademarks, and original metadata remain owned by their publishers and source providers. If you use the API publicly, crediting “Powered by YoBook API” is appreciated.

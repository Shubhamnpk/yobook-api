What YoBook Does

It turns scattered public education records into a browsable catalog and simple API. The project indexes metadata and source links; original books and media remain with their publishers and providers.

Source Priority

CEHRD remains the primary/default source. Other public collections, including Pustakalaya, CDC Library, NCERT, OpenStax, Standard Ebooks, and question-paper collections, are included with clear source attribution.

What You Can Build

  • Textbook search and discovery pages.
  • Teacher-resource dashboards and data checks.
  • Grade, subject, source, and language filters.
  • Reader experiences for cataloged PDF resources.

API Example

Use normal HTTP GET requests from any app, website, script, or learning tool.

GET /api/books?grade=10&subject=Science GET /api/books?source=ncert-official

Attribution And Ownership

The code, normalization logic, and API structure are open source. Textbook PDFs, cover images, trademarks, and original metadata remain owned by their publishers and source providers. If you use the API publicly, crediting "Powered by YoBook API" is appreciated.
